# DBA Schade-assistent

Zelfstandige Next.js-applicatie voor schadebeoordelingen en klantcommunicatie, visueel afgestemd op het DBA Hypothekendashboard.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Source Sans 3
- Lucide React

## Ontwikkelen

```bash
npm install
npm run dev
```
